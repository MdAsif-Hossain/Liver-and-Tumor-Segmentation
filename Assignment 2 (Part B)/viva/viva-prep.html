1 · Basic Terms — what, why, what it does

1.1 Semantic segmentation

What: assigning a class label to every pixel. Our classes: background=0, liver=1, tumour=2. Why: classification says "there is a tumour"; segmentation says "the tumour is here, this shape, this size" — needed for volumetry and treatment planning. Does: outputs a label map the same height×width as the input.

কী: ছবির প্রতিটি পিক্সেলে একটি ক্লাস লেবেল বসানো। আমাদের ক্লাস: background=0, liver=1, tumour=2। কেন: classification শুধু বলে "টিউমার আছে"; segmentation বলে "টিউমার এখানে, এই আকারে" — যা আয়তন মাপা ও চিকিৎসা পরিকল্পনার জন্য দরকার। কাজ: ইনপুটের সমান মাপের একটি label map দেয়।

1.2 Supervised vs Self-supervised learning (SSL)

Supervised: learns from human-made labels (masks). Self-supervised: learns from the images alone by solving a puzzle the data itself defines — no human labels. Why it matters: in medicine, images are cheap (hospitals archive them) but masks are expensive (a radiologist must draw each one). SSL converts cheap unlabelled images into useful features.

Supervised: মানুষের তৈরি লেবেল (mask) থেকে শেখে। Self-supervised: শুধু ছবি থেকেই শেখে — ডেটা নিজেই যে ধাঁধা তৈরি করে তা সমাধান করে, কোনো মানব-লেবেল লাগে না। কেন গুরুত্বপূর্ণ: চিকিৎসা ক্ষেত্রে ছবি সস্তা কিন্তু mask ব্যয়বহুল (রেডিওলজিস্টকে হাতে আঁকতে হয়)।

1.3 Pretext task

What: the fake/auxiliary task used to train an encoder without labels — e.g. "are these two crops from the same image?" or "reconstruct the hidden patches". Why: solving it forces the network to learn real visual structure. Does: produces a pretrained encoder; the pretext head is then thrown away.

কী: লেবেল ছাড়া encoder ট্রেন করার জন্য বানানো কৃত্রিম কাজ — যেমন "এই দুটি crop কি একই ছবির?" বা "ঢেকে রাখা অংশ পুনর্গঠন করো"। কেন: এটি সমাধান করতে গিয়ে নেটওয়ার্ক আসল ভিজ্যুয়াল গঠন শিখে ফেলে। কাজ: একটি pretrained encoder দেয়; pretext head পরে ফেলে দেওয়া হয়।

1.4 Encoder / Decoder / Backbone

Encoder (backbone): compresses the image into feature maps — "what is in it". Decoder (head): expands features back to full resolution — "where exactly". We used ResNet-50 or ViT-S/14 as encoder, and the ASPP head from DeepLabV3 as decoder for all four methods.

Encoder (backbone): ছবিকে feature map-এ সংকুচিত করে — "কী আছে"। Decoder (head): feature থেকে আবার পূর্ণ রেজোলিউশনে ফেরায় — "ঠিক কোথায়"। আমরা encoder হিসেবে ResNet-50 বা ViT-S/14 এবং decoder হিসেবে DeepLabV3-এর ASPP head ব্যবহার করেছি।

1.5 Fine-tuning vs Frozen (linear probing)

Frozen: encoder weights locked; only the decoder trains. Tests how good the features already are. Fine-tuned: encoder also updates (with a much smaller learning rate). A big gap between them means the features are informative but not yet arranged for per-pixel work. Ours: 0.7018 frozen → 0.7757 fine-tuned = +0.0739.

Frozen: encoder-এর weight আটকানো, শুধু decoder ট্রেন হয় — feature এমনিতেই কত ভালো তা যাচাই করে। Fine-tuned: encoder-ও আপডেট হয় (অনেক ছোট learning rate-এ)। দুটির বড় ব্যবধান মানে feature তথ্যবহুল কিন্তু pixel-স্তরের কাজের জন্য এখনো সাজানো নয়।

1.6 Label efficiency

What: how much accuracy you keep when you cut the labels. Our study: fine-tune on 2,553 labelled slices instead of 13,447 = 19% of the labels, and measure what fraction of the supervised score survives (we kept 90.8–97.6%).

কী: লেবেল কমালে কতটুকু নির্ভুলতা টিকে থাকে। আমাদের গবেষণায় ১৩,৪৪৭-এর বদলে মাত্র ২,৫৫৩ লেবেলযুক্ত slice = লেবেলের ১৯% ব্যবহার করে supervised ফলাফলের ৯০.৮–৯৭.৬% ধরে রাখা গেছে।

1.7 Other terms you must know

  • Augmentation / view — a randomly transformed copy of an image (crop, flip, blur). Two views of one image form a "positive pair".
  • EMA (exponential moving average) — a slowly-updated copy of the network: θ_target ← m·θ_target + (1−m)·θ_online. Acts as a stable teacher.
  • Representation collapse — the failure where the encoder outputs the same vector for every image (loss looks perfect, features are useless).
  • Patch token — a ViT splits the image into patches; each becomes a token. 224÷14 = 16, so we get a 16×16 grid of tokens.
  • ASPP / atrous convolution — parallel dilated convolutions that see multiple scales at once without losing resolution.
  • 2.5D input — 3 channels = slices [i−1, i, i+1]. Gives volumetric context cheaply while staying a 2D network.
  • Class imbalance — background 97.67%, liver 2.20%, tumour 0.13%. This is why pixel accuracy is useless here and why we weight the loss.
  • Leakage-safe split — splitting by patient volume, not by slice, because adjacent slices are near-duplicates (Hamming ≈1.9 within a volume vs ≈14.2 across).
Augmentation/view — এলোমেলোভাবে রূপান্তরিত অনুলিপি; একই ছবির দুটি view = positive pair। EMA — ধীরে আপডেট হওয়া নেটওয়ার্ক-অনুলিপি, স্থিতিশীল শিক্ষক হিসেবে কাজ করে। Representation collapse — encoder সব ছবির জন্য একই ভেক্টর দেয় (loss ভালো দেখায়, feature অকেজো)। Patch token — ViT ছবিকে patch-এ ভাগ করে; ২২৪÷১৪=১৬, তাই ১৬×১৬ গ্রিড। ASPP — সমান্তরাল dilated convolution, একসাথে একাধিক স্কেল দেখে। 2.5D — ৩টি চ্যানেল = [i−1, i, i+1] slice। Class imbalance — tumour মাত্র ০.১৩%, তাই pixel accuracy অর্থহীন। Leakage-safe split — slice নয়, রোগীর volume ধরে ভাগ করা।

2 · Equations

2.1 IoU, Dice, mIoU

IoU = TP / (TP + FP + FN)  ·   Dice = 2TP / (2TP + FP + FN)  ·   mIoU = (1/C) Σc IoUc

IoU = overlap ÷ union. Dice counts the overlap twice, so it is always ≥ IoU and is gentler on small objects. mIoU averages IoU over the C=3 classes, so every class counts equally regardless of size — that is why mIoU exposes tumour failure while pixel accuracy hides it.

IoU = মিল ÷ মোট এলাকা। Dice মিলকে দুবার গোনে, তাই সবসময় IoU-এর সমান বা বেশি এবং ছোট বস্তুর প্রতি সদয়। mIoU তিনটি ক্লাসের গড় — প্রতিটি ক্লাস সমান গুরুত্ব পায়, তাই এটি tumour-এর ব্যর্থতা ধরতে পারে, কিন্তু pixel accuracy তা আড়াল করে।

2.2 Sensitivity (recall)

Sensitivity = TP / (TP + FN)

Of all true tumour pixels, what fraction did we find? Clinically the key number — a missed tumour (FN) is worse than a false alarm (FP). DINOv2 = 0.5218, MAE = 0.3018.

প্রকৃত tumour পিক্সেলের কত অংশ আমরা ধরতে পেরেছি। চিকিৎসাগতভাবে সবচেয়ে গুরুত্বপূর্ণ — টিউমার মিস করা (FN) ভুল অ্যালার্মের (FP) চেয়ে খারাপ।

2.3 NT-Xent — SimCLR

ℓi,j = − log [ exp(sim(zi,zj)/τ) ÷ Σk≠i exp(sim(zi,zk)/τ) ]

A softmax over cosine similarities. The numerator is the positive pair (two views of the same image); the denominator includes all negatives (other images in the batch). Minimising it pulls positives together and pushes negatives apart. τ (=0.2) sharpens the distribution: small τ = harsher penalty on hard negatives. Negatives are what prevent collapse.

এটি cosine similarity-র উপর একটি softmax। উপরের অংশ positive pair (একই ছবির দুই view), নিচের অংশে সব negative (batch-এর অন্য ছবি)। এটি minimise করলে positive কাছাকাছি আসে, negative দূরে যায়। τ (=০.২) বণ্টনকে ধারালো করে। negative-ই collapse ঠেকায়।

2.4 BYOL loss + EMA update

L = 2 − 2·cos(p, z)  (symmetrised)  ;   ξ ← m·ξ + (1−m)·θ

The online network's prediction p must match the EMA target's projection z. No negatives. Collapse is prevented by three things together: the extra predictor (asymmetry), the stop-gradient on the target, and the slow EMA (m: 0.996→1) which stops the target from chasing the online network. Our final loss 0.0235 → cos ≈ 0.988.

online নেটওয়ার্কের prediction p-কে EMA target-এর projection z-এর সাথে মেলাতে হয়। কোনো negative নেই। Collapse ঠেকায় তিনটি জিনিস একসাথে: অতিরিক্ত predictor (অসমতা), target-এ stop-gradient, এবং ধীর EMA।

2.5 MAE reconstruction loss

L = ( Σp∈masked |x̂p − xp| + 0.2(x̂p − xp)² ) ÷ |masked|

Loss is computed only on hidden pixels — otherwise the network could win by copying what it can already see. Masking ratio 75%: too low makes the task trivial (nearby pixels give it away); too high leaves too little context to reconstruct anything.

Loss হিসাব হয় শুধু ঢাকা পিক্সেলে — নইলে নেটওয়ার্ক যা দেখতে পাচ্ছে তা নকল করেই জিতে যেত। মাস্কিং ৭৫%: কম হলে কাজটা সহজ হয়ে যায়, বেশি হলে পুনর্গঠনের মতো যথেষ্ট প্রেক্ষাপট থাকে না।

2.6 DINO self-distillation

L = − Σ Pteacher(x) · log Pstudent(x')

Cross-entropy between the teacher's and student's output distributions over different crops. Teacher = EMA of student. Centring (subtract a running mean) stops one dimension dominating and sharpening (low temperature) stops the output becoming uniform — together they prevent collapse.

ভিন্ন crop-এর উপর teacher ও student-এর আউটপুট বণ্টনের মধ্যে cross-entropy। Teacher = student-এর EMA। Centring ও sharpening একসাথে collapse ঠেকায়।

2.7 Our segmentation loss

L = CE(weights [0.3, 1, 6]) + DiceLoss + 0.4·CEaux

Weighted cross-entropy handles imbalance (tumour weighted 6× vs background 0.3×); Dice directly optimises overlap, which CE does not; the 0.4× auxiliary term is DeepLabV3's intermediate supervision.

Weighted CE ভারসাম্যহীনতা সামলায় (tumour ৬×, background ০.৩×); Dice সরাসরি overlap অপ্টিমাইজ করে, যা CE করে না; ০.৪× auxiliary অংশটি DeepLabV3-এর মধ্যবর্তী তত্ত্বাবধান।

2.8 Label-efficiency ratio

Nval / Ntrain = 2,553 / 13,447 = 0.190 → 19%

3.1 Best overall: DINOv2 — why

Self-distillation matches output distributions across multi-crop views, including small local crops. A local crop containing only a lesion must still produce a consistent distribution, so lesion-scale detail is directly rewarded. It also starts from far stronger released weights. Honest caveat: DINOv2 differs in four ways at once (ViT vs ResNet, 224² vs 256², token adapter, pretraining corpus) — so its win is not cleanly attributable to self-distillation alone.

Self-distillation বিভিন্ন আকারের crop-এর উপর আউটপুট বণ্টন মেলায়; ছোট local crop-এ শুধু ক্ষত থাকলেও সেটিকে সামঞ্জস্যপূর্ণ হতে হয়, তাই ক্ষত-আকারের বিবরণ সরাসরি পুরস্কৃত হয়। সতর্কতা: DINOv2 একসাথে চারটি দিকে ভিন্ন, তাই এর জয় শুধু self-distillation-এর কৃতিত্ব নয়।

3.2 The most interesting result: MAE

MAE has the best liver (0.8821) and the worst tumour (0.2873). Pixel reconstruction rewards predicting the dominant intensity of a region. The liver is large, smooth and low-frequency — reconstructing it well pays off enormously in loss terms. A 200-pixel tumour is high-frequency detail whose contribution to the loss is negligible, so the encoder is never pressured to represent it. Lesson: the pretext task decides which structures get encoded, not just how well. This is the cleanest comparison in the study — MAE, SimCLR and BYOL share the identical backbone, resolution and initialisation, so nothing else could explain it.

MAE-তে liver সবচেয়ে ভালো, tumour সবচেয়ে খারাপ। Pixel পুনর্গঠন বড়, মসৃণ, low-frequency অঞ্চলকে পুরস্কৃত করে — liver তেমনই। ২০০ পিক্সেলের tumour high-frequency বিবরণ, loss-এ যার অবদান নগণ্য, তাই encoder সেটি শিখতে বাধ্য হয় না। শিক্ষা: pretext task ঠিক করে দেয় কোন গঠন শেখা হবে। এটিই সবচেয়ে পরিচ্ছন্ন তুলনা — MAE, SimCLR, BYOL-এর backbone ও রেজোলিউশন অভিন্ন।

3.3 Why BYOL was weakest

Final pretext loss 0.0235 → cosine ≈ 0.988 between online and target. That is consistent with partial representation collapse (the predictor is doing almost no work), though not proof. The diagnostic that would settle it: mean per-dimension std of the ℓ₂-normalised projections (healthy ≈ 1/√d; near zero = collapsed).

চূড়ান্ত pretext loss ০.০২৩৫ → cosine ≈ ০.৯৮৮। এটি আংশিক collapse-এর সাথে সঙ্গতিপূর্ণ (predictor প্রায় কিছুই করছে না), তবে প্রমাণ নয়। নিশ্চিত হওয়ার পরীক্ষা: ℓ₂-normalised projection-এর প্রতি-মাত্রা গড় স্ট্যান্ডার্ড ডেভিয়েশন (সুস্থ হলে ≈ ১/√d)।

3.4 Why SSL beat supervision on tumour but not liver

With 13,447 labels the supervised model has ample signal for the liver — labels are not the bottleneck, so SSL adds little. For tumour (0.13% of pixels) even 13,447 labels give few positive pixels, so the supervised model is label-limited; SSL pretraining on unlabelled images supplies structure that partly substitutes. SSL's benefit is largest where label signal is scarcest.

১৩,৪৪৭ লেবেল থাকায় liver-এর জন্য supervised মডেলের যথেষ্ট সংকেত আছে — লেবেলই বাধা নয়। কিন্তু tumour (০.১৩%) এর জন্য লেবেল সংকেত কম, তাই SSL-এর গঠনগত জ্ঞান কাজে লাগে। যেখানে লেবেল-সংকেত সবচেয়ে কম, SSL-এর লাভ সেখানে সবচেয়ে বেশি।
The number you must be careful with. "101% of supervision" comes from the checkpoint selected on the test set — the maximum of 50 noisy evaluations, so it is biased upward. The unbiased epoch-50 figure is 0.7492 = 97.6%. Always quote both and name the bias.
যে সংখ্যাটি নিয়ে সাবধান। "১০১%" এসেছে test set-এ বাছাই করা checkpoint থেকে — ৫০টি কোলাহলপূর্ণ মূল্যায়নের সর্বোচ্চ, তাই এটি স্ফীত। নিরপেক্ষ epoch-50 মান ০.৭৪৯২ = ৯৭.৬%।

Q2. The test split is used to monitor AND to report. Why is that a departure, and what does it do to your numbers?

Normally a test set is touched exactly once. Here we pick the best of 50 test evaluations, which is the maximum of 50 noisy measurements → biased upward. We measured the bias: +0.011 to +0.032 mIoU. Remedy would be a fourth held-out split; we could not afford it with only 2,553 labelled slices.

সাধারণত test set একবারই ছোঁয়া হয়। এখানে ৫০টি মূল্যায়নের সর্বোচ্চটি বাছাই করায় ফল স্ফীত হয় — আমরা মেপেছি: +০.০১১ থেকে +০.০৩২ mIoU। সমাধান হতো চতুর্থ একটি হোল্ড-আউট ভাগ।
Q3. SimCLR/BYOL: show your two-view augmentation. Which transforms are essential?

Show: the ssl_view Albumentations pipeline. Essential: RandomResizedCrop (forces the model to match different parts/scales of the same anatomy — this carries almost all the learning signal) and HorizontalFlip. Deliberately weak: colour jitter, because CT slices are effectively grayscale, so colour invariance teaches almost nothing.

অপরিহার্য: RandomResizedCrop (একই অঙ্গের ভিন্ন অংশ/স্কেল মেলাতে বাধ্য করে) ও HorizontalFlip। ইচ্ছাকৃতভাবে দুর্বল: colour jitter — CT ছবি প্রায় সাদাকালো।
Q4. MAE: show your masking code. What fraction, and what if too few / too many?

Show: create_patch_mask() — 16×16 patches, ratio 0.75. Too few masked: the task becomes trivial — neighbouring visible pixels reveal the answer, so the encoder learns only local interpolation. Too many: not enough context remains, the task becomes unsolvable and the encoder learns nothing useful.

খুব কম ঢাকলে: পাশের দৃশ্যমান পিক্সেল থেকেই উত্তর মেলে, তাই শুধু স্থানীয় interpolation শেখে। খুব বেশি ঢাকলে: যথেষ্ট প্রেক্ষাপট থাকে না, কাজটি অসম্ভব হয়ে যায়।
Q5. DINOv2: explain multi-crop and the student/teacher loss.

2 global crops (224², wide view) + 4 local crops (98², zoomed). The teacher sees only global crops; the student sees all. The student must predict the global (whole-object) distribution from a local patch — that is what forces local–global consistency. Loss = cross-entropy between teacher and student distributions; teacher = EMA of student, with centring + sharpening to avoid collapse.

২টি global crop (২২৪²) + ৪টি local crop (৯৮²)। Teacher শুধু global দেখে, student সব দেখে। student-কে ছোট অংশ থেকে সম্পূর্ণ বস্তুর বণ্টন অনুমান করতে হয় — এটিই local–global সামঞ্জস্য তৈরি করে।
Q6. Show the adapter that reshapes ViT tokens into a 2-D map. Why is it necessary?

Show: token_feature_map(). A ViT outputs a sequence (B, N, C); a convolutional decoder needs a grid (B, C, H, W). We drop the CLS token and reshape (B, 256, C) → (B, C, 16, 16), asserting H·W = N. Also say: because that grid is only 16×16 we reduced ASPP dilations to (3,6,9) — the standard (6,12,18) would exceed the grid and degenerate.

ViT দেয় ক্রম (B,N,C); convolution decoder চায় গ্রিড (B,C,H,W)। CLS token বাদ দিয়ে (B,256,C) → (B,C,16,16) করা হয়। গ্রিড মাত্র ১৬×১৬ বলে ASPP dilation (৩,৬,৯)-এ নামানো হয়েছে।
Q7. Walk through the frozen-vs-fine-tuned experiment. What changed, what did you observe?

Optimiser change: frozen → requires_grad=False on the encoder, one param group (head only, LR 2e-4). Fine-tuned → two param groups, encoder unfrozen after a 2-epoch head warm-up at LR 1e-5 (20× smaller). Observed: 0.7018 → 0.7757 (+0.0739), and the frozen curve declined after epoch 2 while its training loss kept falling — the head was overfitting 2,553 images with no ability to reshape the features.

পরিবর্তন: frozen-এ encoder-এ requires_grad=False, একটি param group; fine-tuned-এ দুটি group, ২ epoch warm-up-এর পর encoder খুলে LR ১e-৫ (২০× ছোট)। পর্যবেক্ষণ: ০.৭০১৮ → ০.৭৭৫৭, এবং frozen curve ২য় epoch-এর পর নামতে থাকে।

B · Theory questions

Q8. What does "self-supervised" mean precisely — how does a pretext task supervise without labels?

The supervision signal is constructed from the data itself. We already know the answer without a human: we know which two crops came from the same image, we know the pixels we hid, we know what the teacher network output. So a normal supervised loss can be computed — the "label" is generated by the procedure, not annotated by a person.

তত্ত্বাবধানের সংকেত ডেটা থেকেই তৈরি। কোন দুটি crop একই ছবির, কোন পিক্সেল আমরা ঢেকেছি, teacher কী দিয়েছে — সবই আমরা জানি। তাই স্বাভাবিক supervised loss হিসাব করা যায়; "লেবেল" পদ্ধতিই তৈরি করে, মানুষ নয়।
Q9. Explain NT-Xent. What role do negatives play?

See §2.3. Negatives supply the repulsive force. Without them the trivial solution "map everything to one point" would make the numerator maximal — the loss would be perfect and the features useless. Negatives make that solution expensive, so SimCLR cannot collapse.

Negative বিকর্ষণ জোগায়। এগুলো না থাকলে "সবকিছুকে এক বিন্দুতে পাঠাও" সমাধানটিই সেরা হতো — loss নিখুঁত, feature অকেজো। Negative সেই সমাধানকে ব্যয়বহুল করে।
Q10. Why doesn't BYOL collapse without negatives? Role of stop-gradient / EMA?

Three mechanisms together: (1) the predictor makes the two branches asymmetric, so they cannot trivially agree; (2) stop-gradient means the target is never optimised to make the loss small; (3) the EMA target changes slowly, so it acts as a stable moving goalpost the online network chases but never instantly matches. Remove the predictor or the stop-gradient and BYOL does collapse.

তিনটি ব্যবস্থা একসাথে: (১) predictor দুই শাখাকে অসম করে; (২) stop-gradient-এর কারণে target কখনো loss কমানোর জন্য অপ্টিমাইজ হয় না; (৩) EMA target ধীরে বদলায়। predictor বা stop-gradient সরালে BYOL সত্যিই collapse করে।
Q11. In MAE, why is 75% masking feasible and beneficial, unlike ~15% in NLP?

Images are highly redundant — a missing patch can usually be guessed from its neighbours. At 15% the task is trivial (pure local interpolation, no semantics learned). Language is far denser in information: each word carries much more, so hiding 75% of words would leave the sentence unrecoverable. So 75% is what makes the vision task hard enough to force semantic understanding.

ছবিতে প্রচুর পুনরাবৃত্তি — অনুপস্থিত patch পাশের patch থেকেই অনুমান করা যায়। ১৫% ঢাকলে কাজটি তুচ্ছ হয়ে যায়। ভাষায় প্রতিটি শব্দ অনেক বেশি তথ্য বহন করে, তাই ৭৫% শব্দ ঢাকলে বাক্য পুনরুদ্ধার অসম্ভব। ৭৫% মাস্কিং দৃষ্টি-কাজটিকে যথেষ্ট কঠিন করে অর্থগত বোঝাপড়া আদায় করে।
Q12. What is self-distillation in DINOv2? How do student and teacher differ and how is the teacher updated?

The network teaches itself: the student is trained by gradient descent to match the teacher's output distribution. They share architecture but not weights — the teacher's weights are an EMA of the student's (ξ ← mξ + (1−m)θ), never trained directly. The teacher sees only global crops, the student sees local ones too, forcing local→global consistency.

নেটওয়ার্ক নিজেই নিজেকে শেখায়: student gradient descent-এ teacher-এর আউটপুট বণ্টন মেলাতে শেখে। স্থাপত্য এক, weight আলাদা — teacher-এর weight student-এর EMA, সরাসরি ট্রেন হয় না।
Q13. Linear probing vs fine-tuning. What does a large gap suggest?

Probing freezes the encoder and trains only a small head — it measures how directly usable the representation is. Fine-tuning updates everything. A large gap (ours: +0.0739) means the features contain the right information but are not arranged for the task — the head alone cannot extract it, so the encoder must move. A small gap would mean the representation is already task-ready.

Probing encoder জমিয়ে রাখে — feature সরাসরি কতটা ব্যবহারযোগ্য তা মাপে। বড় ব্যবধান মানে তথ্য আছে কিন্তু কাজের উপযোগী করে সাজানো নেই। ছোট ব্যবধান মানে representation আগে থেকেই প্রস্তুত।
Q14. Why can an SSL encoder match a supervised one with far fewer labels? What is transferred?

What transfers is general visual structure — edges, textures, shapes, part–whole relationships, and what makes regions similar or different. Labels are then only needed to name those structures and refine boundaries, which takes far fewer examples than learning the structures from scratch. The encoder learned from 13,447 unlabelled images; the labels only had to teach the final mapping.

যা স্থানান্তরিত হয় তা হলো সাধারণ ভিজ্যুয়াল গঠন — প্রান্ত, বুনট, আকৃতি, অংশ-সমগ্র সম্পর্ক। লেবেল তখন শুধু সেই গঠনগুলোর নামকরণ ও সীমানা ঠিক করার জন্য লাগে, যাতে অনেক কম উদাহরণ যথেষ্ট।
